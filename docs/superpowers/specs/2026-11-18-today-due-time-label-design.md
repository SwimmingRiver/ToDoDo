# 오늘 화면 마감 표시에 시각·남은 시간 추가

- 날짜: 2026-11-18
- 브랜치: `feat/today-due-time-label`
- 출처: 유저 피드백(11-16) — "오늘 화면의 D-1 같은 마감 표시에 날짜만 말고 시간도 나오면 좋겠다"

## 의도

오늘 화면에서 마감이 얼마나 임박했는지를 날짜 단위가 아니라 실제 시각 기준으로 보여 준다.
지금은 당일 마감이면 아침이든 마감 10분 전이든 "D-day"만 보이고, 마감 시각이 지나도 자정까지 "D-day"로 남는다.

## 표시 규칙

| 마감 | 표시 |
|---|---|
| 오늘, 마감 시각 전 | `3시간 남음`, 1시간 미만이면 `40분 남음` |
| 오늘, 마감 시각 지남 | `2시간 지남` (1시간 미만이면 `40분 지남`) |
| 1~3일 남음 | `D-1 · 14:30` |
| 4일 이상 남음 (지금 TimeLabel 자리) | `14:30` |
| 하루 이상 지남 | `2일 초과` (변경 없음) |

- 시각은 24시간제 `HH:mm` (폭 절약). 기존 `formatDueTime`의 "오후 2시"(분 버림)를 대체한다.
- 자정(00:00) 마감은 "시간 정보 없음"으로 보는 기존 규칙 유지: 시각을 붙이지 않고, 당일이면 `D-day`.
- 긴급도 색상(`getUrgency`: 당일·지남 danger, 3일 이내 soon)은 변경 없음.
- 기간 항목의 마지막 날이 아닌 날은 기존대로 `D-n`.

## 범위

- 웹: `client/src/features/today/components/todayTodoItem.tsx`, `client/src/shared/utils/formatToday.ts`(+ 새 라벨 함수)
- 앱: `mobile/src/shared/ui/todayTodoItem/TodayTodoItem.tsx`(DateTodosSheet도 이 컴포넌트 사용), `mobile/src/shared/ui/dueBadge/DueBadge.tsx`, `mobile/src/shared/utils/formatToday.ts`
- 화면을 켜 둔 채 시간이 흘러도 맞도록 1분 간격으로 현재 시각을 갱신한다.

**범위 밖:** 목록·캘린더·상세 화면의 시각 표기, 긴급도 기준 변경, `getDueBadgeLabel`을 쓰는 다른 곳(`dueTodo.tsx` 등).

## 접근 방식

- A. 시각만 붙이기(`D-day · 18:00`) — 당일 마감이 지나도 "D-day"로 남는 문제를 못 풂.
- B. 모든 마감을 시간 단위로(`29시간 남음`) — 며칠 남은 일은 셈이 필요해 오히려 읽기 어려움.
- **C. 당일만 남은/지난 시간, 그 외는 D-n + 시각 (채택)** — 사용자 제안(몇 시간 전)과 폭 절약(14:30)을 반영.

## 구현에 맡기는 것

- 라벨 계산은 순수 함수(`now`를 인자로)로 두고 웹·앱에 각각 둔다(기존 due.ts·formatToday.ts도 웹/앱 복제 구조).
- 1분 갱신 장치의 형태(행마다 vs 화면 단위)는 구현자 판단. 행 수만큼 타이머가 생기지 않게 할 것.
- 테스트는 시스템 시간 mock으로 고정, 절대 날짜 하드코딩 금지. 경계값: 59분/60분, 정확히 마감 시각, 자정 마감, 내일 00:30 같은 날짜 경계. `TZ=America/New_York`에서도 실행.
