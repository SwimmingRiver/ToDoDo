# 스크린샷 데모 데이터

스크린샷은 공개 자료이므로 실제 개인 데이터를 쓰지 않는다. 운영 Firebase를 쓰되 **전용 데모 계정 하나에만** 데이터를 넣는다. 다른 사용자의 데이터는 건드리지 않는다.

## 넣는 방법 — 제안

| 안 | 방법 | 장점 | 단점 |
|---|---|---|---|
| **1 (추천)** | 데모 Apple ID(또는 Google 계정)로 앱에 가입 → `scripts/seedDemoTodos.ts`(새로 만듦)로 그 uid에만 할 일을 넣음 → `grant:entitlement`로 프리미엄 부여 | 날짜가 실행일 기준으로 계산돼 언제 찍어도 "오늘"이 꽉 찬다. 다시 찍을 때 `--reset`으로 지우고 재생성 가능. 심사 데모 계정과 같이 쓸 수 있음 | 스크립트 작성 필요(작음, grantEntitlement와 같은 admin SDK 패턴) |
| 2 | 데모 계정으로 앱에서 손으로 입력 | 코드 없음 | 20여 개 입력, 다시 찍을 때마다 날짜가 지나 다시 입력 |
| 3 | 에뮬레이터 + 로컬 앱 | 운영 완전 분리 | 통계·AI 플랜·캘린더 연동은 Worker까지 로컬로 띄워야 해 손이 많이 감 |

스크립트 안전장치(1안): `--uid` 필수, 대상 계정 이메일이 허용 목록(데모 계정)과 다르면 거부, 생성 문서에 표식 없이도 `--reset`은 그 uid 문서만 지운다. 반복 할 일은 스크립트가 회차 생성 규칙(`docs/data-model/recurring-todos.md`)을 재구현하지 않도록 **앱에서 손으로 2개만 만든다**(아래 ★). → 스크립트는 사용자 승인 후 별도 PR로 만든다(이번 PR에는 없다).

## 데모 할 일 세트 (D = 시드 실행일)

화면 후보 순서는 `docs/mobile-release.md` §스크린샷과 같다.

### 1. 오늘 화면 — D에 6개, 그중 2개 완료(진행률 33%)
| 제목 | 우선순위 | 일정 | 상태 |
|---|---|---|---|
| ★ 아침 스트레칭 10분 | 보통 | 매일 반복 07:30 | 완료 |
| 팀 주간 회의 자료 정리 | 높음 | D 10:00 마감 | 진행 중 |
| 운동 — 러닝 5km | 보통 | D 19:00 | 할 일 |
| ★ 영어 단어 30개 외우기 | 낮음 | 매주 월·수·금 | 할 일 |
| 장보기 (우유, 달걀, 사과) | 낮음 | D 18:00 | 완료 |
| 디자인 시안 피드백 회신 | 높음 | D 17:00 마감 | 할 일 |

주간 날짜 줄에 점이 찍히도록 D-2~D+4에 1~3개씩 더 분산(아래 프로젝트 하위 할 일이 자연스럽게 채움).

### 2. 목록 — 하위 할 일이 있는 큰 일 3개
- **포트폴리오 사이트 완성** (높음, 마감 D+21) — 하위: 레퍼런스 조사(완료) · 와이어프레임(완료) · 메인 페이지 디자인(진행 중, D+3) · 프로젝트 소개 글 작성(D+7) · 배포(D+20)
- **이사 준비** (보통, 마감 D+14) — 하위: 이삿짐센터 견적 비교(완료) · 전입신고(D+15) · 인터넷 이전 신청(D+5) · 버릴 짐 정리(D+2)
- **제주도 여행 계획** (낮음, 마감 D+30) — 하위: 항공권 예매(완료) · 숙소 예약(D+4) · 일정표 만들기(D+10)

### 3. AI 플랜 — 목표 입력 예시
`다음 달까지 토익 800점 만들기` (마감 D+30) → 생성된 미리보기 화면을 찍는다(저장 전). 실제 AI 호출이라 결과가 매번 다르니 잘 나온 것을 고른다. 하루 횟수 제한(20회) 주의.

### 4. 캘린더 — 월간
위 할 일들의 마감이 이달에 퍼져 보이도록 이미 배치됨. 구글 캘린더 오버레이는 **데모용 구글 계정**을 연동하고 그 계정 캘린더에 일정 3~4개(예: "치과 예약", "친구 생일 저녁", "분기 회의")를 만들어 둔다. 개인 구글 계정 연동 금지.

### 5. 통계 — 지난 4주 완료 기록
통계는 `doneAt` 기준이라 스크립트가 D-28~D-1에 완료 할 일 30~40개를 하루 0~3개씩 넣는다(연속 달성일이 보이게 최근 7일은 매일 ≥1). 우선순위는 높음:보통:낮음 ≈ 3:5:2. `archived` 대상(30일 지난 done)이 되지 않게 D-28 이내로만.

### 6. 할 일 상세 — ★ 영어 단어 30개 외우기 (매주 월·수·금, 종료일 D+60)

## 촬영 규격

- **필수: iPhone 6.9형 1320×2868(세로)** 최소 1장, 최대 10장. 6.9형을 올리면 작은 화면은 App Store Connect가 축소해 쓴다. iPhone 전용이라 iPad 스크린샷은 불필요.
- 출처가 엇갈림: 일부 자료는 6.5형(1242×2688)으로 대체 가능하다고 함 — 제출 시점에 App Store Connect의 미디어 관리 화면에서 최종 확인. 6.9형으로 찍으면 어느 쪽이든 안전.
- 촬영: iPhone 18 Pro Max(6.9형) 시뮬레이터 + `xcrun simctl io booted screenshot <파일>`. 상태 막대 정리: `xcrun simctl status_bar booted override --time 9:41 --batteryState charged --batteryLevel 100 --cellularBars 4`.
- 라이트 모드로(앱이 `userInterfaceStyle: light`).
- 프리뷰 영상은 선택 — 이번엔 생략 추천.
